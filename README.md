# UnitSync

Converts units between the metric and imperial system

## Supported units

* **Length**
    * kilometer
    * meter
    * centimeter
    * millimeter
    * mile
    * foot
    * inch
    * yard
* **Temperature**
    * celsius
    * fahrenheit
    * kelvin
* **Mass**
    * kilogram
    * gram
    * milligram
    * pound
    * ounce
* **Volume**
    * liter
    * milliliter
    * gallon
    * quart
    * pint
    * fluid_ounce

## Installation

1. `git clone git@github.com:arvid-e/unit-sync.git`
2. `cd UnitSync`
3. `npm install`

## Usage

`npm start`  
`Conversion command: 60 kilogram to pound`  
`Result: 132.2775 pound`  
`Conversion command: 10 inch to centimeter`  
`Result: 25.4000 centimeter`  
`Conversion command: exit`
